# 🐍 Snake Evolution

A classic Snake game developed using Godot Engine 4.7.2 and GDScript.

## 🎮 Features

- Classic Snake gameplay
- Keyboard controls
- Food collection
- Increasing score
- Increasing snake speed
- Pause and resume
- Game Over screen
- Restart functionality
- Wall collision detection
- Snake self-collision detection

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ / W | Move Up |
| ↓ / S | Move Down |
| ← / A | Move Left |
| → / D | Move Right |
| SPACE | Pause / Resume |
| R | Restart |

## ⚙️ Built With

- Godot Engine 4.7.2
- GDScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in Godot Engine 4.7.2.
3. Open `scenes/game.tscn`.
4. Run the project.
